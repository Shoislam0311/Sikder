# Technology Stack Reference

Sikder is a Next.js 16 and React 19 application written in TypeScript. It uses Tailwind CSS 4, Radix UI primitives, Zustand, React Hook Form, Zod, Prisma, SQLite, NextAuth, next-intl, Framer Motion, Recharts, and a Bun-based production runtime. The authoritative dependency list is `package.json`, while the data model is in `prisma/schema.prisma`.
